# CIFAR-10 CNN Image Classifier

A Deep Learning based image classification project built using PyTorch and Convolutional Neural Networks (CNNs).

---

## Features

- Built using PyTorch
- CNN architecture
- CIFAR-10 dataset
- Image preprocessing
- Model evaluation
- Custom image prediction

---

## Classes

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

---

## Technologies Used

- Python
- PyTorch
- Torchvision
- PIL
- Deep Learning

---

## Installation

```bash
pip install -r requirements.txt
```

---

## Run Training

```bash
python main.py
```

---

## Run Prediction

```bash
python predict.py
```
